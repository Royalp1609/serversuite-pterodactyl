# Security policy

Please report security problems privately, not in a public issue: use
**Security → Report a vulnerability** on this repository
(GitHub private vulnerability reporting).

Include the Server Suite and Pterodactyl versions, what an attacker can do,
and steps to reproduce. You'll get a reply within a few days. Fixes ship as a
new release; the release notes say when one is a security fix.

Only the latest release is supported.
